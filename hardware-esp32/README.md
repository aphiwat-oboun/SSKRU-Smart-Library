# โค้ดบอร์ดจริง (ESP32 + HLK-LD2410C mmWave Radar)

ไฟล์ **[esp32_ld2410c_real.ino](./esp32_ld2410c_real.ino)** ออกแบบสำหรับบอร์ด ESP32 จริงและเซนเซอร์เรดาร์ **HLK-LD2410C** (ไม่ได้ใช้ PIR และไม่ต้องลง Library เพิ่มใน Arduino IDE)

---

## การต่อสาย (Wiring)

### โหมดที่ 1: UART2 (แนะนำ — แยกคนเคลื่อนไหวและคนนั่งนิ่งอ่านหนังสือได้ + จำกัดระยะไม่ให้ทะลุผนัง)
ตั้งค่าในโค้ด: `const bool LD2410_USE_UART = true;`

| ขา HLK-LD2410C | ต่อเข้าขา ESP32 | หมายเหตุ |
| :--- | :--- | :--- |
| **VCC (5V)** | **VIN / 5V** | LD2410C ต้องใช้ไฟ 5V (ห้ามใช้ 3.3V) |
| **GND** | **GND** | กราวด์ร่วม |
| **TX** | **GPIO 16 (RX2)** | ขา TX ของเรดาร์เข้า RX2 ของ ESP32 |
| **RX** | **GPIO 17 (TX2)** | ขา RX ของเรดาร์เข้า TX2 ของ ESP32 |

### โหมดที่ 2: ขา OUT เส้นเดียว (ต่อสายง่ายสุด)
ตั้งค่าในโค้ด: `const bool LD2410_USE_UART = false;`

| ขา HLK-LD2410C | ต่อเข้าขา ESP32 |
| :--- | :--- |
| **VCC (5V)** | **VIN / 5V** |
| **GND** | **GND** |
| **OUT** | **GPIO 27** |

### อุปกรณ์แสดงผล (Optional)
| อุปกรณ์ | ขา ESP32 |
| :--- | :--- |
| LED สีเขียว (มีคนในห้อง) | GPIO 26 |
| LED สีแดง (ห้องว่าง) | GPIO 25 |
| Buzzer | GPIO 14 |
| TM1637 CLK / DIO | GPIO 18 / GPIO 19 |

---

## ก่อนอัปโหลดลงบอร์ดจริง (Arduino IDE)
แก้แค่ **3 จุด** ด้านบนของไฟล์ `esp32_ld2410c_real.ino`:
1. `WIFI_SSID` และ `WIFI_PASSWORD` → ชื่อและรหัสผ่าน Wi-Fi 2.4GHz ของห้องสมุด
2. `ROOM_ID` / `DEVICE_ID` / `ROOM_NUMBER_INT` → ตั้งให้ตรงกับห้องที่นำไปติดตั้ง (`ROOM_01`–`ROOM_04`)
3. `MAX_DETECT_DISTANCE_CM` → ปรับระยะตรวจจับให้พอดีกับขนาดห้อง (ค่าเริ่มต้น `450` ซม.)
